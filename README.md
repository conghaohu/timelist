# TimeList 使用教程

## 一、软件概述

TimeList 是一个时间管理工具，帮助用户规划每日任务并按权重管理优先级。支持日/周/月视图以及工作/学习/生活分类图表。

---

## 二、登录

启动软件后进入登录界面：

- **用户名**：输入 `test`
- **密码**：输入 `test`
- 点击 **登录** 按钮，或在密码框直接按 **回车** 登录
- 点击 **首页** 可返回登录界面重新登录

> 当前为演示版本，账号密码固定为 `test` / `test`。

---

## 三、主界面布局

主界面分为三个区域：

| 区域 | 说明 |
|------|------|
| 左侧导航栏 | 切换不同视图（日/周/月/工作/学习/生活） |
| 中间表格区 | 显示当前视图的任务表格 |
| 右侧编辑栏 | 编辑开始时间、结束时间、待办事项、权重 |

顶栏从左到右依次为：**首页**、**日历**、**当前时间**、**设置**、**导出**。

---

## 四、视图说明

### 4.1 日视图

显示一天 24 小时（0:00-23:00）的日程表，每行包含 **时间** 和 **任务** 两列，简洁直观。

**用途**：按小时规划一天的任务。

### 4.2 周视图

显示 24 小时 × 7 天的周计划表，适合按周规划。

### 4.3 月视图

显示 31 天 × 12 个月的年度总览表，适合查看全年任务分布。

### 4.4 工作图表

动态表格，点击 **添加行** 按钮可新增一行（默认时间 8:00）。适合管理不固定时间的工作任务。

### 4.5 学习图表

预置了固定时间段（08:00-09:40、10:00-11:40 等），适合课程表式的学习计划。

### 4.6 生活图表

预留的生活分类视图，可根据需求自定义使用。

## 五、任务操作

### 添加任务

1. 点击表格中的任意单元格
2. 在右侧编辑栏中设置：

   | 字段 | 说明 |
   |------|------|
   | 开始时间 | 任务开始时刻 |
   | 结束时间 | 任务结束时刻 |
   | 待办事项 | 任务描述 |
   | 权重 | 优先级（1-10，数值越大越重要） |

3. 点击 **保存任务** 按钮

### 查看任务

点击已保存的单元格，右侧编辑栏会自动加载该任务的完整信息。

### 修改任务

点击已有任务的单元格，修改右侧内容后重新点击 **保存任务** 即可覆盖。

### 清除任务

点击已有任务的单元格，再点击 **重置** 按钮，该单元格内容将被清空。

## 七、顶部功能

### 首页

点击 **首页** 返回登录界面，可用于切换账号或重新进入。

### 日历

点击 **日历** 弹出日历控件，方便查看日期。

### 当前时间

顶栏中部实时显示当前日期和时间（yyyy-MM-dd hh:mm:ss），每秒自动刷新。

### 设置

点击 **设置** 打开设置窗口，包含以下选项：

| 选项 | 说明 |
|------|------|
| 默认视图 | 启动时自动切换到选中的视图 |
| 表格配色 | 切换整体配色（默认/海洋蓝/森林绿/落日橙） |
| 默认权重 | 新建任务时权重输入框的初始值 |
| 字体大小 | 表格中文字的字体大小 |
| 任务提醒 | 开启后每 30 秒检查一次，任务到结束时间弹窗提醒 |

所有设置自动保存，关闭程序后不丢失。

### 导出

点击 **导出** 将当前表格保存为 CSV 文件，可用 Excel 直接打开查看。

## 八、常用操作流程

### 示例：规划一天的工作

1. 登录后点击左侧 **日视图**
2. 点击某个时间对应的单元格
3. 在右侧设置：开始 09:00、结束 10:30、事项"项目会议"、权重 8
4. 点击 **保存任务**
5. 单元格变为桃红色，悬停可见完整信息

### 示例：管理工作图表

1. 切换到 **工作图表**
2. 点击 **添加行** 增加一行
3. 双击时间列修改具体时间
4. 点击对应单元格，在右侧编辑内容后保存

### 示例：调整软件设置

1. 点击顶栏 **设置**
2. 修改默认视图为"日视图"，配色为"海洋蓝"
3. 点击 **确定** 即可生效

---

## 九、注意事项

- 开始时间和结束时间建议按实际填写，方便后续统计
- 权重值 1-10，建议合理分配，避免全部设为最高值
- 重置操作会清空单元格内容且不可撤销
- 添加行按钮仅在工作图表中可用，其他视图已预置固定行数
- 开启任务提醒后，任务到达结束时间会弹出提醒窗口
